# Calibrate speaker decisions on a meeting

1. In a saved meeting with retained audio, choose **Export calibration data**. The app writes `mic.wav` and/or `system.wav` plus `labels.json` to a new folder you choose. This is an explicit plaintext export; keep the folder private. Deleting the app's retained audio later does not delete your export.
2. Review **every** row in `labels.json` while listening to the audio. Fill `truePerson` with the person's consistent name and `trueOverlap` with `true` or `false`. Verify `start` and `end`, especially rows marked `approximate`; fill missing ends. The exported `currentLabel`, `corrected`, `textHash`, and timing are evidence, not ground truth. Do not change `synthetic` to make a fixture look like owner audio.
3. From the repository root, run `npm run calibrate -- --meeting /absolute/path/to/exported-folder`. If the local speaker model is missing, run `npm run download:diarization-models` once and repeat the calibration command. The command reads the WAV tracks, measures voiced energy, extracts embeddings with the same local CAMPPlus model used for speaker identification, and evaluates each row against other labelled rows from the meeting. It requires at least two reviewed people and two clean, non-overlapping rows per person. It writes `calibration-report.json` in that folder and prints the full threshold sweep and recommendation. Send the report file when discussing results; the WAV remains local.
4. In **Settings → People → Speaker calibration**, import `calibration-report.json`. Inspect the draft and click **Apply these values**. Importing alone changes nothing. Manual values without an owner-audio report remain labelled **Uncalibrated guess**. A synthetic report never marks settings calibrated.

The table varies similarity floor, runner-up margin, minimum voiced seconds, and overlap tolerance. It reports right-person, refusal, and overlap-detection rates for each combination. The summary also gives final-pass change rate and corrections per minute. The selection score is `2 × right − 4 × wrong − refusal − 3 × missed overlap`; this preference for refusing over naming the wrong person is a policy choice, not a measured fact.

**Limits:** This is a small, within-meeting leave-one-row-out estimate, not a guarantee on future meetings. Voiced duration uses an RMS energy proxy with a guessed 0.01 cutoff. Overlap duration uses intersecting transcript rows with different reviewed people, so overlapping voices within a single row can be missed. These approximations are stated in the report. The report does not silently change settings. Other speaker guards, including anchor and voice enrollment quality thresholds, remain uncalibrated guesses until separately measured.

For a demonstration with invented scores, run `node scripts/fixtures/create-synthetic-calibration.js /tmp/openwhispr-synthetic-calibration` followed by `npm run calibrate -- --meeting /tmp/openwhispr-synthetic-calibration`. Its report says **synthetic** and must not be used as owner evidence.
